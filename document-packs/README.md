# 文档扩展包生成配方

本目录在公开工作区中只保存可复现的抓取、筛选和检查脚本。抓取到的 HTML、来源清单、
发现/审计 JSON、人工选择结果以及最终 ZIP 都是本地生成物，不进入此仓库。

当前公开配方：

- `cn-tales-002/fetch.mjs`
- `task-forces/fetch.mjs`
- `task-forces/inspect-candidates.mjs`
- `task-forces/inspect-sitemap-candidates.mjs`

运行前请检查脚本目标站点的使用条款、限速和许可。生成后的 SCP 内容不得直接提交到本仓库；
如果未来决定公开某一文档包，必须为每篇文档补齐来源、作者署名和 CC BY-SA 3.0 许可信息，
并在发布前单独审查。
